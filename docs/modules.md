
# Project Modules

## 1. Frontend Module
Responsible for displaying the user interface and allowing users to interact with the application.

## 2. Backend Module
Responsible for processing user requests and handling the application logic.

## 3. API Module
Responsible for connecting the frontend and backend and transferring data between them.

## 4. Data Management Module
Responsible for storing, retrieving and managing application data.

## 5. Testing Module
Responsible for checking whether the application components work correctly.

## 6. Documentation Module
Responsible for maintaining project information, architecture and development details.
